# 变化定位任务（数字键版）

这是 1、2、3、8、9、0 按键版。正式组仍使用 4 或 6 个色块、250 ms 学习阵列、4 组共 80 个正式试次。现有部署仍使用 Supabase 与本地 Excel，本次未迁移到 JATOS。选择本地导出时，Excel 和手动下载链接会先就绪，不等待服务器；结束页分别显示两种结果。服务器状态仍为上传中时，请暂勿关闭页面。

- 组别 0 只导出本机 Excel，不会新建 Supabase 客户端，也不会提交试次。
- 如研究方案需要同一人配对，请由主试分配不含真实身份信息的匿名码（6–64 个英文字符、数字、下划线或短横线，首位为字母或数字）。跨任务按原样使用此码；留空仍自动生成单次匿名码。不同运行的会话标识独立生成，本版本不支持刷新后断点续做。
- 正式试次中切换标签页、窗口失焦或退出已经进入的全屏会记录中断。回到实验页面后按空格继续下一试次。中断既不当作超时，也不进入两种 K 口径的分母。无有效试次时，剔除超时口径的正确率和 K 在 Excel 中留空。
- 平均 RT 只使用正确且有效的试次；逐试次仍保留错误反应的 RT。选择色和正确色记录的是探测画面中实际显示的颜色。
